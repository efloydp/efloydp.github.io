# 촘촘 작업 타이머 v1

Windows용 포터블 작업 타이머입니다. 설치 없이 실행하며 카운트다운·스톱워치와 실제 프로그램 활동 시간을 기록합니다.

[최신 v1 다운로드](https://github.com/efloydp/efloydp.github.io/raw/refs/heads/main/downloads/CChomWorkTimer/v1/CChomWorkTimer-v1.zip)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 카운트다운·스톱워치 | 시·분·초를 입력합니다. 0초에서 시작하면 스톱워치로 동작합니다. |
| 편리한 숫자 편집 | 정지·일시정지 중 한 번 클릭, 실행 중 더블클릭으로 편집합니다. 두 자리 입력 후 다음 칸 이동, Enter 확정·Esc 현재 칸 취소를 지원합니다. 깜빡이는 커서는 숨깁니다. |
| 시작·일시정지·두 단계 리셋 | 첫 리셋은 정지·기존 설정 시간 복원, 시간 제한 없이 다음 리셋은 0초 초기화입니다. 시작·편집·증감하면 첫 단계부터 다시 동작합니다. |
| 시간 빠른 조정 | 메인은 −30 / −10 / +10 / +30분, 미니는 ±10분입니다. 작은 원형 테두리 버튼이며 0초에서도 추가할 수 있습니다. 감소로 0초가 되면 정지합니다. |
| 프리셋 | 추가하면 새 타이머(20분·파스텔색)가 즉시 생성됩니다. 수정에서 이름·시간·색상 변경, 목록에서 표시 여부·삭제·드래그 정렬을 지원합니다. |
| 프로그램별 포커스 기록 | 등록한 프로그램이 전면에 있고 입력 활동이 있을 때 집계합니다. 입력이 없는 중지 기준은 1~600초 중 선택하며 기본은 3초입니다. 입력 내용은 수집하지 않습니다. |
| 작업 리포트 | 주간·월간·기간 지정으로 포커스·타이머 합계, 이전 기간 대비 증감, 그래프와 프로그램별 포커스 비중을 설정 탭에서 바로 조회합니다. |
| 오늘 누적 시간 | 작은 상태 점과 오늘 포커스·타이머 시간을 한 줄로 표시하며 클릭으로 전환합니다. 표시를 끌 수 있습니다. |
| 미니 창 | 최소화 시 한 줄 미니 창을 표시합니다. 이동 핸들, 시간 편집, 시작·일시정지·리셋·±10분·열기를 지원합니다. 일반 최소화로 변경할 수 있습니다. |
| 종료 알림·1분 예고 | 시스템 또는 화면 완료 알림, 앱 알림음 3종·무음·음량 조절을 지원합니다. 1분 예고는 입력 포커스를 가져오지 않는 말풍선이며 메인·미니 창의 이동을 따라갑니다. |
| 색상·테마 | 밝은·어두운 테마, 숫자·UI 색상 HEX 직접 입력과 통일 버튼을 지원합니다. 콜론은 숫자 색상보다 옅게 표시합니다. UI 색상은 메인·미니 버튼과 아이콘에 적용됩니다. |
| 창·단축키·트레이 | 항상 위, 크기 조절, 위치 기억, 전역 단축키와 고정 곰 시계 트레이 아이콘을 지원합니다. 곰 귀 옵션은 제거했습니다. |

전역 단축키는 **Ctrl + Alt + F8** 시작·일시정지, **F9** 창 열기, **F10** 리셋입니다. 모두 Ctrl+Alt 조합이며 설정에서 끌 수 있습니다.

리포트의 프로그램 비중은 포커스 기록 기준입니다. 진행 중인 주·월은 이전 같은 날짜 범위와 비교하고, 기간 지정은 직전 같은 길이의 기간과 비교합니다. 목표 기능은 없습니다.

## 기본 설정

배포 ZIP에는 사용자 설정과 개인 기록을 포함하지 않습니다. 새 폴더에서 실행하면 아래 기본값으로 시작합니다.

| 프리셋 | 시간 | 색상 | 메인 표시 |
| --- | --- | --- | --- |
| 짧은 집중 | 20분 | `#D2DCE3` · 하늘 회색 | 켜짐 |
| 긴 집중 | 1시간 | `#E0DDF2` · 연보라 | 켜짐 |
| 아주 긴 집중 | 2시간 | `#CCCCCC` · 회색 | 꺼짐 |

밝은 테마, 숫자·UI 기본색, 항상 위와 최소화 시 미니 창 표시가 기본값입니다. 사용자 지정 프리셋·색상·등록 프로그램은 배포하지 않습니다.

## 실행과 업데이트

1. Windows 10/11에서 ZIP을 압축 해제합니다. .NET Framework 4.x가 필요합니다.
2. `CChomWorkTimer.exe`를 실행합니다. 설치·관리자 권한은 필요하지 않습니다.
3. 기존 사용자는 종료 후 EXE를 교체하고 **기존 Data 폴더를 유지**하면 설정·기록을 이어 쓸 수 있습니다. 기존 폴더에서는 기존 설정이 우선합니다.

설정은 프리셋 / 일반 설정 / 포커스 프로그램 / 작업 리포트의 네 탭입니다. 배포 전 수정 버전은 계속 v1로 관리합니다.

# 촘촘 작업 타이머 v1

작업 시간을 재고, 실제로 활동한 프로그램의 시간을 따로 기록하는 Windows용 포터블 타이머입니다.
설치 없이 실행하며 밝은·어두운 테마와 작은 미니 창을 지원합니다.

[촘촘 작업 타이머 v1 다운로드](https://github.com/efloydp/efloydp.github.io/raw/refs/heads/main/downloads/CChomWorkTimer/v1/CChomWorkTimer-v1.zip)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 카운트다운·스톱워치 | 시·분·초 숫자를 직접 눌러 시간을 설정합니다. `00:00:00`에서 시작하면 경과 시간을 세는 스톱워치로 동작합니다. |
| 시작·일시정지·리셋 | 언제든 멈추고 다시 시작할 수 있습니다. 리셋하면 처음 입력한 시간으로 돌아가며, 이미 기록한 작업 시간은 유지됩니다. |
| 타이머 프리셋 | 자주 쓰는 시간에 이름과 색상을 붙여 등록합니다. 메인 창에 표시할 프리셋을 고르고, 버튼 한 번으로 바로 시작할 수 있습니다. |
| 완료 알림 | 시간이 끝나면 Windows 시스템 알림 또는 앱의 화면 알림 중 선택한 방식으로 알려 줍니다. |
| 타이머 작업 기록 | 카운트다운이나 스톱워치가 실행된 시간을 날짜별로 기록합니다. 일시정지한 시간은 제외합니다. |
| 프로그램별 포커스 기록 | 등록한 프로그램이 전면에 있고 마우스·키보드 입력이 있을 때 기록합니다. 3초간 입력이 없으면 기록을 멈추고 활동을 재개하면 다시 집계합니다. |
| 기간별 기록 조회 | 시작일과 종료일을 선택해 포커스·타이머 기록을 조회합니다. 포커스는 프로그램별로 합산하고, 타이머는 날짜별 기록과 총 시간을 표시합니다. |
| 오늘 누적 시간 | 메인 창에서 오늘의 포커스 시간과 타이머 시간을 클릭으로 전환해 확인합니다. 표시를 끌 수도 있습니다. |
| 미니 창 | 최소화하면 작은 창에서 시간을 확인하고, 숫자 편집·시작·일시정지·리셋·메인 창 열기를 사용할 수 있습니다. 설정에서 일반 최소화로 바꿀 수 있습니다. |
| 창 배치 | 항상 위에 표시, 창 크기 조절, 마지막 위치 기억을 지원합니다. 설정 창도 타이머 가까이에 열립니다. |
| 밝은·어두운 테마 | 밝은 화면과 어두운 화면을 선택할 수 있습니다. 곰 귀 옵션을 켜면 테마에 따라 흰곰·흑곰 모양으로 표시됩니다. |
| 트레이 | 고정 곰 시계 아이콘을 표시하며, 마우스를 올리면 현재 시간과 실행 상태를 확인할 수 있습니다. |

기본 프리셋은 **짧은 집중 20분 / 긴 집중 1시간 / 아주 긴 집중 2시간**입니다. 처음에는 짧은 집중과 긴 집중이 메인 창에 표시되며, 수정할 수 있습니다.

포커스 기록은 기본적으로 타이머가 멈춰 있어도 활동한 시간을 집계하며, 타이머 실행 중에만 기록하도록 바꿀 수 있습니다.
화면 잠금·절전 중에는 기록을 제외하고 타이머를 일시정지합니다. 입력 내용이나 클릭 위치는 수집하지 않습니다.

## 실행과 업데이트

1. Windows 10/11에서 ZIP을 압축 해제합니다. .NET Framework 4.x가 필요합니다.
2. `CChomWorkTimer.exe`를 실행합니다. 설치와 관리자 권한은 필요하지 않습니다.
3. 기존 사용자는 앱을 종료한 뒤 EXE를 교체하고 **기존 `Data` 폴더를 유지**하세요. 설정과 기록이 이 폴더에 저장됩니다.

개인 기록은 배포 ZIP에 포함하지 않았습니다. 현재 버전은 배포 전 수정도 계속 **v1**로 관리합니다.

## 작업표시줄 고정 아이콘

EXE에 여러 해상도의 곰 시계 아이콘을 내장했습니다. 기존 고정 아이콘이 기본 Windows 아이콘으로 보이면 고정을 해제하고, 앱을 종료한 뒤 EXE를 교체하세요. 압축을 푼 고정된 폴더에서 앱을 실행해 다시 작업표시줄에 고정하면 됩니다. 기존 `Data` 폴더는 유지하세요.

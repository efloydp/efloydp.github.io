# 촘촘 작업 타이머 v1 보안 점검

점검일: 2026-10-14. 소스와 새로 빌드한 배포 EXE를 점검했습니다. 악성 동작을 발견하지 않았지만, 이 문서는 백신 인증이나 모든 PC에서의 안전성을 보증하는 인증서가 아닙니다.

## 권한과 개인정보

- 설치 없는 포터블 앱이며 관리자 권한을 요청하지 않습니다. 실행 권한은 asInvoker, uiAccess=false입니다.
- 앱에 외부 통신, 자동 업데이트, 원격 전송, 시작 프로그램 등록, 셸 명령 실행 코드는 없습니다. 제작자 계정 링크를 직접 클릭할 때만 고정된 HTTPS 주소를 기본 브라우저로 엽니다.
- 포커스 기능은 전면 프로그램 이름과 마지막 입력 이후 경과 시간만 확인합니다. 키 입력 내용, 클릭 위치, 창 제목, 문서 내용, 클립보드를 수집하지 않습니다.
- 선택된 프로그램 이름과 날짜별 누적 시간은 실행 파일 옆 Data/work-timer.xml에 평문으로 저장됩니다. 이 기록과 백업을 다른 사람에게 공유하면 작업 이력이 전달됩니다. 배포 ZIP에는 개인 Data를 넣지 않았습니다.

## 적용한 강화

1. 폰트는 EXE에 내장한 바이트를 메모리에서 직접 등록합니다. 기존 임시 폴더의 폰트를 읽거나 재사용하지 않습니다. 글꼴은 이 프로세스에서만 사용됩니다.
2. 네이티브 DLL의 기본 검색 경로를 Windows System32로 제한했습니다. 현재 작업 폴더의 DLL을 검색하지 않는지 시험했습니다. Windows 10/11을 대상으로 합니다.
3. 기록 XML은 DTD와 외부 엔티티를 금지하고 외부 리졸버를 사용하지 않습니다. 파일 및 문자 크기는 32MB, XML 중첩은 16단계로 제한합니다.
4. 날짜, 중복 날짜, 문자열 길이, 항목 수, 비정상 숫자를 검증합니다. 음수·NaN·무한대인 작업 시간과 손상된 데이터를 거부합니다. 기존 정상 기록과 설정의 호환성 검증도 수행했습니다.
5. 저장은 무작위 이름의 새 임시 파일을 사용하고 원자적으로 교체하며 이전 파일을 .bak로 보존합니다. Data 폴더와 기록/백업 파일의 리디렉션 링크에 대한 쓰기를 거부합니다. 연결 폴더에서 실제 저장 차단을 시험했고 대상 폴더는 비어 있었습니다. 같은 사용자 권한의 공격자가 실행 파일 자체나 상위 폴더를 조작하는 상황까지 완전히 막는다는 의미는 아닙니다.
6. 테스트·미리보기 명령과 테스트 클래스를 배포 EXE에서 제외했습니다. 검증용 빌드는 build.ps1 -Verification으로 별도 생성합니다.

## 검증 결과

- 보안 입력 검증 14개: 외부/내부 DTD, XML 깊이·크기, 비정상 작업 시간·날짜·문자열, 원자 저장과 임시 파일 정리, 메모리 폰트, DLL 검색 경로 시험 통과.
- 핵심 동작 44개, UI 회귀 77개와 창 위치 3개 검증 통과. 시작/일시정지, 기록 저장, 포커스 유휴 감지, 미니 창, 알림, 스톱워치 실행 검증도 통과.
- 배포 EXE에서 테스트 클래스와 Preview 메서드가 없음을 확인했습니다. 의존성은 .NET Framework/Windows 구성 요소와 내장 Pretendard 폰트입니다.
- Microsoft Defender 검사를 두 환경에서 시도했지만 실제 Windows 로그가 Product/Feature disabled, 0x80004005를 반환했습니다. 백신 검사는 완료되지 않았으며 악성코드 미검출 판정을 받은 상태가 아닙니다. VirusTotal 등 외부 서비스에 파일을 업로드하지 않았습니다.

2026-10-15: 앱 고정 아이콘 리소스 추가 후 보안 검증 14개와 UI 회귀 77개·창 위치 3개, 실행 검증을 실제 Windows 환경에서 다시 통과했습니다. Windows Shell이 EXE에서 곰 시계 아이콘을 16px·32px로 추출하는 것을 확인했습니다. 실제 작업표시줄의 고정 캐시를 조작하거나 보안 설정을 변경하지 않았습니다.

## 다른 PC에서의 Windows 경고

현재 EXE는 Authenticode 서명이 없습니다. 다른 PC에서는 SmartScreen의 알 수 없는 앱 경고가 나올 수 있고 Smart App Control 또는 회사 정책이 실행을 차단할 수 있습니다. 정식 코드 서명도 새 파일의 모든 경고를 즉시 없앤다고 보장하지 않습니다. 자체 서명 인증서로 이 문제를 해결한 것처럼 표시하지 않았습니다. 보안 기능이나 백신을 끄도록 안내하지 않습니다.

정식 대외 배포에서는 신뢰되는 발급기관의 코드 서명과 실제 대상 PC의 백신 검사를 추가로 진행하는 것이 적절합니다. 새 PC에서는 ZIP을 먼저 풀고 일반 사용자 권한으로 실행하세요. 개인 기록이 필요하면 기존 Data 폴더를 따로 보관하거나 옮기세요.

SHA256SUMS.txt는 배포 파일의 SHA-256입니다. 전송 중 손상·변경 확인용이며 게시자 신원을 증명하는 코드 서명을 대체하지 않습니다.

## v1 추가 도구 보안 범위

전역 단축키는 Windows RegisterHotKey/UnregisterHotKey로 등록·해제하며 키보드 후킹이나 입력 내용 수집을 사용하지 않습니다. 충돌하는 키를 강제로 빼앗지 않습니다. 알림음 WAV는 메모리에서 생성하며 파일 다운로드·외부 음원 실행을 하지 않습니다. 음량은 생성 음원의 진폭만 조절합니다. 포커스 유휴 판정은 기존 GetLastInputInfo의 경과 시간만 사용합니다. 새 옵션은 기존 로컬 XML에 저장되며 추가 네트워크 연결이나 관리자 권한을 요구하지 않습니다.

## 2026-10-16 작업 리포트 통합

주간·월간·기간 지정 집계와 프로그램 비중은 기존 Data XML을 로컬에서 계산합니다. 외부 전송·새 권한·추가 DLL 다운로드는 없습니다. 목표 기능과 별도 리포트 창은 제거했습니다. 구형 XML의 목표 설정 항목은 무시하며 기존 작업 기록은 유지됩니다. 예시 기록과 검증 코드는 배포에 포함하지 않습니다.
